¿Qué es SuperProfes?

Identifica automáticamente el procedimiento que falla en cada respuesta — no solo si es correcta o incorrecta.

Arquitectura · Backend + Frontend

🔗 Backend · NestJS

API REST serverless en AWS Lambda + Prisma ORM.

  • /auth — login, register, roles
  • /attempts — POST respuestas, GET historial
  • /skills — catálogo de habilidades
  • /mastery — cálculo de p_known
  • /classrooms — gestión de cursos
  • /alerts — detección automática

⚡ AI Engine · Python

Claude Haiku para análisis de errores no catalogados.

  • Rule engine · 50+ patrones
  • Knowledge tracing · Bayesian
  • OCR extraction · Gemini 2.0
  • Async job queue · Celery

🎨 Frontend · React + Astro

UI responsiva para 3 roles distintos.

  • Teacher — heatmap, alertas
  • Student — práctica interactiva
  • Parent — resumen semanal
  • Landing — Astro con SEO
