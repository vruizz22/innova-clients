# Parent App — UI kit

Expo (mobile). Mint-leaning. Reassuring tone, **no raw probabilities** — uses categorical labels ("Va bien", "En proceso", "Necesita apoyo").

## Surfaces

- **ParentHeader** — child avatar + settings.
- **ParentSummary** — week summary + per-skill rows + teacher recommendation.
- **SupervisionFlow** — supervised mode toggle, daily notifications, share-with-teacher, privacy panel.
- **PushStack** — iOS lockscreen with 3 mock SuperProfes pushes (assignment, completion, daily summary).

## Privacy stance

The privacy block is visible inline in supervisión, with the spec'd reassurance copy: photos anonymized, EXIF stripped, no third-party trackers.
